## Como rodar um projeto

É preciso ter o Node.js instalado. Exemplo com o Far Away:

```bash
cd "The Ultimate React Course 2025 React, Next.js, Redux, More/05-travel-list"
npm install
npm run dev
```

`npm run dev` abre o projeto em modo de desenvolvimento (Vite). `npm run build` gera a versão de produção e `npm run preview` a abre localmente. O Tip Calculator roda do mesmo jeito, a partir da pasta `07.3-challenge-tip-calculator`.

## O resto do repositório

As outras pastas dentro de "The Ultimate React Course 2025 React, Next.js, Redux, More" são exercícios e desafios das aulas, na ordem do curso (por exemplo `03.1-challenge-1-profile-card-v1`, `04-steps` e `10.0-usepopcorn`). São exercícios de estudo, não projetos autorais.

A pasta `ultimate-react-course-main` é o material de apoio do próprio curso (código do instrutor), guardado para consulta. Não é trabalho meu.
